# Skin Cancer CNN Analysis (7대 피부 질환 이미지 분류 모델)

의료 영상 데이터 전처리부터 모델 학습, 5-Fold 교차 검증, 실전 예측까지 구현한 딥러닝 파이프라인 프로젝트입니다[cite: 23, 27].

## 🚀 프로젝트 개요

- **목적**: CNN 기반 아키텍처를 활용하여 미세한 피부 병변(7대 질환)을 정확하게 분류하고 진단을 보조하는 모델 개발[cite: 23, 26]
- **개발 기간**: 개인 프로젝트
- **주요 성과**: 테스트셋 기준 **94.8%**의 높은 예측 정확도 달성

## 🛠️ Tech Stack

- **Language**: Python[cite: 23]
- **Deep Learning**: TensorFlow / Keras[cite: 23]
- **Data Manipulation**: Pandas, NumPy[cite: 23]
- **Visualization**: Matplotlib, Seaborn[cite: 23]
- **Evaluation**: Scikit-Learn[cite: 23]
